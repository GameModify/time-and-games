# Time & Games

Локальное приложение на Vue 3 и TypeScript для учёта времени, параллельных занятий, игр, фильмов и сериалов. Node.js + Express + SQLite. Интерфейс на русском, светлая и тёмная темы, адаптация под небольшие экраны. Аккаунт и облако не нужны.

## Запуск на Windows

Установи **Node.js 24.12 LTS или новее** с npm. Открой **«Запустить Time & Games.bat»**. При первом запуске установятся зависимости; затем соберётся актуальный интерфейс и откроется [приложение](http://127.0.0.1:3535). Оставь окно сервера открытым.

Первый запуск требует интернет для npm. Сам трекер работает без сети. Интернет нужен для поиска Steam и кинокаталога, импорта библиотеки аккаунта и загрузки постеров. Внешние шрифты и аналитика не используются.

Если глобальная команда npm сломана, используй `node scripts/npm.ts` вместо `npm`. Помощник запускает npm из папки установленного Node.js.

```powershell
node scripts/npm.ts ci
node scripts/npm.ts run dev
```

Для разработки интерфейс доступен на [127.0.0.1:5173](http://127.0.0.1:5173), API — на порту 3535. Для обычного запуска:

```powershell
node scripts/npm.ts run build
node server/index.ts
```

Для совместимости с сетевыми фильтрами Windows launcher добавляет `--tls-max-v1.2` только к своим процессам. При аналогичной ошибке в терминале перед npm можно выполнить `$env:NODE_OPTIONS='--tls-max-v1.2'`. Проверка сертификатов остаётся включённой.

## Возможности

- Читаемые размеры текста и контролов при масштабе 100%. Тема переключается в верхней панели и настройках, выбор сохраняется в этом браузере.
- Игровое время вводится отдельными полями часов и минут; нули показаны подсказками, поля можно очистить. Карточки показывают время, а библиотека — количество игр и сводку. Пройденные игры фильтруются по месяцу, году, прошлым периодам и отсутствию даты прохождения.
- Обзор дня показывает часы, недели и месяца — дни. Столбцы используют цвета категорий. Полные заметки доступны в разделе «Записи и результаты» под таймлайном. Выделение текста с отпусканием мыши за формой не закрывает редактор.
- Завершённые вручную записи считаются по указанным границам целиком, даже если окончание позже текущего времени; только активные таймеры считаются до текущего момента. Время игры по связанным сессиям считается за всю историю, объединяя пересечения. На карточке используется большее из времени по таймеру и общего времени из Steam/ручного ввода, чтобы не складывать одни и те же часы дважды.
- Несколько независимых таймеров, например «Кодинг» + «Видео». Можно остановить один или все, добавить заметку о результате. Активные таймеры сохраняются в БД и переживают закрытие вкладки и перезапуск сервера; время простоя также входит в сессию до её остановки.
- Ручные записи, редактирование начала и окончания, ночные сессии, привязка к игре.
- Экраны открываются по обычным адресам: `/`, `/games`, `/media`, `/statistics`, `/settings`. Работают обновление страницы, прямые ссылки и кнопки «Назад»/«Вперёд». Параметры календаря добавляются только при отличии от стандартных; старые ссылки с `#page=...` поддерживаются.
- Таймлайн с отдельными колонками для пересекающихся занятий, список, обзор недели и месяца. Нажатие на запись открывает редактирование; на день в обзоре — его таймлайн.
- Аналитика за выбранный период. «Учтено» — объединение интервалов; «Работа» — объединение рабочих интервалов. Внутри каждой категории время также не дублируется, но параллельные разные категории учитываются независимо. Поэтому сумма категорий может быть больше общего времени.
- Библиотека игр: поиск, статусы, оценки от 0,5 до 10 с шагом 0,5, отзыв, даты начала и прохождения, постеры и поиск по каталогу Steam. Вручную можно добавить любую игру без Steam.
- Сердечко на обложке добавляет игру, фильм или сериал в избранное. Отбор «Все / Избранное» сочетается с поиском, статусом и типом. В играх период не меняет выбранную вкладку: для «Играю», «На паузе» и «Брошена» используется дата начала, для пройденных игр дата прохождения, в общей вкладке соответствующая статусу дата.
- Цвет личной оценки зависит от значения: 7,5–10 золотой, 4–7 нейтральный, 0,5–3,5 красный. Одинаковая шкала используется на обложках и в редакторе звёзд; нейтральный цвет адаптирован к светлой и тёмной темам.
- Общая статистика показывает количество завершённых игр, фильмов и сериалов, время на завершённые и общее время каждой библиотеки. График по месяцам с выбором года раскрывает обложки завершённых историй. Записи без даты показаны отдельно. Эти значения не прибавляются к итогу таймлайна; время на обложке относится ко всему прохождению или просмотру, а не только к месяцу завершения.
- Библиотека фильмов и сериалов: статусы «К просмотру», «Смотрю», «Просмотрено», «На паузе», «Заброшено», личная оценка звёздами с шагом 0,5 и отзыв. Поиск Cinemeta работает без ключа, в том числе по русскому названию, и загружает обложку, рейтинг IMDb, хронометраж, сезоны и серии. Русские названия подставляются из Wikidata по точному IMDb ID. При отсутствии перевода или недоступности Wikidata сохраняется оригинальное название; описания каталога могут быть на английском. Карточку можно изменить или заполнить вручную.
- Прогресс сериала сохраняет сезон и последнюю просмотренную серию. Кнопка следующей серии переходит между сезонами. Время просмотра рассчитывается приблизительно по хронометражу либо вводится вручную и хранится только в библиотеке: в таймлайн и статистику дня оно не добавляется. Данные каталога обновляются кнопкой в карточке; личные оценки не отправляются в IMDb.
- Даты начала и окончания просмотра можно указать в карточке. При новом переходе в «Смотрю» дата начала заполняется текущим днём, при завершении заполняется дата окончания. У старых записей отсутствующие даты не подменяются текущими.
- Импорт установленных игр Steam, включая дополнительные библиотеки из `libraryfolders.vdf`. При нестандартной установке укажи папку Steam. Для всей библиотеки аккаунта нужны SteamID64 и Steam Web API Key; ключ не сохраняется. Повторный импорт пропускает игры с уже существующим Steam App ID и сохраняет твои оценки и заметки.
- Свои группы и категории, цвета и признак «Работа». Категорию с записями нельзя удалить до их переноса. Удаление игры сохраняет сессии времени, убирая только ссылку на игру.
- Экспорт и восстановление JSON. Восстановление **заменяет** данные; требуется подтверждение в интерфейсе. Перед заменой экспортируй текущую базу. Ошибка в копии откатывает операцию целиком.

## Данные и приватность

В настройках есть сброс всех записей, игр, фильмов, сериалов и пользовательских категорий. Он требует ввода `СБРОСИТЬ`; стандартные категории восстанавливаются автоматически. Перед сбросом можно скачать резервную копию. Сброс выполняется одной транзакцией. Оформление браузера сохраняется.

Все записи хранятся в `data/time-and-games.sqlite`. По умолчанию сервер слушает только `127.0.0.1`. Дополнительный доступ по домашней сети включается явно. Запросы записи с посторонних сайтов и не-JSON запросы отвергаются. База, экспорты, ключи и зависимости не входят в Git.

Для резервной копии во время работы сервера используй экспорт JSON в настройках. Новый формат версии 2 включает киноколлекцию; копии версии 1 также поддерживаются. Восстановление старой копии заменит всю базу, включая очистку киноколлекции. SQLite-файл копируй при остановленном сервере: при работе есть также WAL/SHM-файлы. Постеры хранятся как ссылки; их отображение без сети зависит от кэша браузера. Поисковые запросы кинокаталога передаются Cinemeta, IMDb ID результатов передаются Wikidata для русских названий, обложки загружаются с внешних серверов. Личные оценки и заметки остаются локально.

Даты календаря и границы суток используют локальный часовой пояс компьютера; интервалы в API — Unix timestamp в миллисекундах. `TNG_PORT` меняет порт, `TNG_DATA_DIR` — каталог базы, `TNG_STEAM_PATH` — дополнительную папку Steam. Для нестандартного порта запускай сервер напрямую; Vite proxy рассчитан на 3535.

## Локальный API для CLI и будущего ИИ

Базовый адрес: `http://127.0.0.1:3535/api`. Все запросы записи требуют `Content-Type: application/json`.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/health`, `/bootstrap` | Состояние сервера, категории, игры, киноколлекция и активные таймеры |
| GET | `/sessions?from=<ms>&to=<ms>` | Все сессии, пересекающие полуоткрытый диапазон |
| POST | `/sessions` | Создать одну или несколько сессий |
| PATCH / DELETE | `/sessions/:id` | Изменить или удалить сессию |
| GET / POST | `/categories`, `/games` | Список и создание |
| PATCH / DELETE | `/categories/:id`, `/games/:id` | Изменение и удаление |
| GET | `/steam/search?q=...` | Поиск в Steam |
| POST | `/steam/import-installed` | Сканирование; необязательное поле `steam_path` |
| POST | `/steam/import-owned` | Импорт; поля `steam_id`, `api_key` |
| GET / POST | `/media` | Список и добавление фильма или сериала |
| PATCH / DELETE | `/media/:id` | Изменение и удаление карточки |
| GET | `/media/search?q=...&kind=movie` | Поиск Cinemeta; `kind`: `movie` или `series` |
| GET | `/media/catalog/:imdb_id?kind=series` | Метаданные и серии |
| POST | `/media/:id/next-episode` | Отметить следующую серию |
| GET / POST | `/export`, `/import-backup` | Выгрузка / восстановление |

Пример тела `POST /sessions`:

```json
{
  "category_ids": ["work-code", "fun-video"],
  "start_at": 1792742400000,
  "end_at": 1792746000000,
  "note": "Работал над сайтом, параллельно смотрел видео"
}
```

Без `start_at` используется текущее время, без `end_at` создаётся активный таймер. Одновременно может быть только один активный таймер каждой категории. `PATCH /sessions/:id` с `end_at` останавливает таймер. Голос и ИИ пока не подключены; обычный облачный чат сам не имеет доступа к localhost.

## Проверки и GitHub

Фронтенд организован по pages-first принципу FSD 2.1: app, pages, features, entities, shared. Обоснование, правила зависимостей и актуальные официальные источники — в [docs/architecture.md](docs/architecture.md). Границы импортов автоматически проверяются в `npm run check`.

Весь прикладной код, сервер, тесты и инструменты написаны на TypeScript. Включены `strict`, проверка индексов массивов/словарей, неиспользуемого кода и всех путей возврата. ESLint использует `strictTypeChecked` и правила Vue: запрещены `any`, небезопасные операции, необработанные промисы и лишние утверждения типов. Предупреждения также останавливают проверку. `vue-tsc` проверяет скрипты и шаблоны компонентов. Входные JSON-данные проверяются Zod; типы API выводятся из общих схем.

`npm run typecheck` запускает только проверку типов. `npm run format` применяет Prettier. Сервер и тесты выполняются встроенной поддержкой TypeScript в Node.js, без отдельного runtime-компилятора. Существующая SQLite-база обновляется при запуске без потери записей.

Работа ведётся в feature-ветках, затем PR в `main` со squash merge. Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md). Полные проверки выполняются после законченной задачи, перед коммитом/PR:

```powershell
node scripts/npm.ts run verify
```

CONTRIBUTING.md и скрипты scripts/quality фиксируют правила типизации, функций до 20 строк, когнитивной сложности до 20 и архитектурных границ. `npm run quality:audit` проверяет эффективные настройки всех исходников, тестов и скриптов; `npm run verify` выполняет этот аудит и полный набор проверок.

Тесты API создают отдельную временную SQLite-базу, проверяют перезапуск сервера, параллельные таймеры, валидацию, связи игр и атомарность восстановления. Тесты времени проверяют пересечения, границы суток, недели/месяцы и расположение параллельных сессий.

GitHub Actions выполняет проверки на PR в `main` и изменениях `main`. Защита ветки на стороне GitHub зависит от тарифа и настроек репозитория; файл правил сам по себе не блокирует прямой push.

## Автоматический учёт

Фоновый сбор выполняет отдельный [Activity Tracker](https://github.com/GameModify/activity-tracker). Сайт запускается без него. В Настройки → Автоматический учёт можно подключить локальный сервис, настроить категории, правила и автоматическое принятие завершённых интервалов. По умолчанию подключение выключено; неопознанные занятия ожидают проверки.

Подключение хранится только на сервере сайта. Ключ не возвращается в браузер и не включается в резервные копии. Импорт повторяемый: один интервал не создаётся дважды, ручные изменения и удаления сохраняются. Пересечения с уже записанным временем выбранной категории вычитаются перед добавлением. Если сервис недоступен, ручные функции сайта продолжают работать.

Сброс сайта очищает настройки подключения и локальную очередь. История независимого сервиса сохраняется в его собственной базе. Подробности: [интеграция трекера](docs/tracking.md).
## Пауза занятий

Ручное занятие можно поставить на паузу и продолжить той же кнопкой. Счётчик суммирует рабочие отрезки, а перерывы остаются пустыми на таймлайне и не входят в статистику. Пауза сохраняется после обновления страницы, перезапуска сервера и в резервной копии версии 3; старые копии версий 1 и 2 поддерживаются.

При включённом автоматическом добавлении текущий интервал трекера показывается до последнего подтверждённого сигнала. После паузы плеера он сохраняется как обычная запись. Перерывы и потеря связи не продолжают счётчик. Главная показывает название видео, воспроизведение/паузу и доступную позицию плеера. Синхронизация выполняется каждые 5 секунд, поэтому изменения могут появляться с небольшой задержкой.

## Чаты, документы и игры

В расширении отдельно включается проверка действий для выбранных сайтов. Чат учитывается только после действия в его активной вкладке; смена окна прекращает учёт сразу, пять минут без действий приостанавливают его. Текст переписки и значения клавиш не сохраняются.

Windows-сборщик получает активное приложение. Для Word путь сохранённого документа берётся из открытого экземпляра Office и сверяется с идентификатором окна. Правило «Путь документа / В папке и подпапках» позволяет отнести выбранную папку к science; прочие документы имеют метку documents. Без подтверждённого пути папка не определяется по одному названию. В проверке интервалов можно запомнить категорию конкретного документа. Steam-приложение определяется по пути исполняемого файла и связывается с одноимённой игрой библиотеки.

Отрезки одного автоматического занятия за день объединяются в одну карточку с суммарной длительностью и перерывами. На временной шкале сохраняются реальные промежутки. Внутри карточки доступны отдельные отрезки.

Discord учитывается отдельным источником только при подтверждённой голосовой связи. Если клиент не предоставляет элементы доступности, состояние остаётся неизвестным и голосовое время не добавляется.

Дневной график показывает подписанные дорожки занятий с горизонтальной шкалой времени. Паузы остаются пустыми, длительность считается по объединению реальных отрезков. Доступны весь день, диапазон активности и подробный масштаб; выбор дорожки открывает её итог и отдельные интервалы для редактирования. Полноэкранное неизвестное приложение можно один раз отметить как игру. Дальше сохранённое правило применяется и вне полного экрана.

## Доступ из домашней сети

В корне проекта создай `.env` с адресом сетевого интерфейса компьютера:

```dotenv
TNG_LAN_HOST=192.168.1.10
```

Перезапусти сервер. С другого устройства в той же сети открой `http://192.168.1.10:3535`.
Адрес `http://127.0.0.1:3535` продолжает работать на основном компьютере.
Укажи фактический адрес из `ipconfig`; при смене IP обнови `.env` и перезапусти приложение.
Чтобы отключить сетевой доступ, удали `TNG_LAN_HOST` или оставь значение пустым.
Для нового порта можно отдельно задать `TNG_PORT`.

Допускается только выбранный частный IPv4-адрес; сервер не слушает все интерфейсы.
HTTP проверяет адрес клиента, Host и Origin. В брандмауэре разрешай TCP-порт 3535
только для частного профиля и локальной подсети. Не настраивай проброс порта на роутере.
Авторизации в приложении нет: устройства с разрешённым доступом могут читать и менять данные.
Сервис Activity Tracker остаётся на `127.0.0.1:3536`; подключаться к нему с другого устройства не требуется.
Файл `.env` исключён из Git.
